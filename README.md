# Grind & Glow

Grind & Glow is a full-stack e-commerce coffee shop website.

## Features

- Browse coffee products, bakery items and merchandise
- Products are loaded dynamically from MySQL database
- Add products to basket
- Remove products from basket
- Checkout form with validation
- Admin page to update product prices
- Responsive design for desktop and mobile

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run

1. Install packages:

npm install

2. Start the server:

node server.js

3. Open browser:

http://localhost:3000

## Database

Database name: grindglow

Tables:
- products
- basket
